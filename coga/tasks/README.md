# Task queues

The [numbered v1 execution queue](v1/README.md) contains the work retained for
first users and the 1.0 release. Use `coga status v1 --order-by slug` for its
current state. The [v2 wish list](_v2/README.md) holds deferred work and is
excluded from ordinary status, launch, validation, and Dream discovery.

Terminal tickets outside these queues retain their existing paths and await
the ordinary retirement process. Recurring templates and period identities
are unchanged.
