---
name: code/address-pr-comments
description: Address requested PR changes while preserving the owner's review gate.
---

Read `branch:` and `pr:` under `## Dev`. Switch to the recorded branch if
needed and stop if Git refuses. Read the applicable PR comments and ask the
owner about ambiguous or conflicting requests. Make the requested changes,
run the applicable checks, and commit and push the fixes and ticket notes
on the branch. Leave the final bump and merge to the owner.
